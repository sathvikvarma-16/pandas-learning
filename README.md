- Data selection, indexing, and modification
- Reading and writing files

- Data cleaning and validation
- Filtering, sorting, and ranking

- String and datetime operations
- Merging, joining, and concatenation
- Reshaping and pivot tables
- Numerical analysis and exploratory data analysis (EDA)
- Preparing features and targets for machine learning
- Performance and memory optimization
- Advanced Pandas techniques

## Tools

- Visual Studio Code
